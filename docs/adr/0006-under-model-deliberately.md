# Under-model deliberately: the relationships cannot be written today

The cases cannot be enumerated today and the relationships cannot be written out today, so the design is a tiny mechanical core plus everything else free, which is not vagueness everywhere. Completing the model is satisfying and mostly wrong; a thing enters the typed core when evidence and a reader for it exist, and a graveyarded thing does not come back without a new ruling.
