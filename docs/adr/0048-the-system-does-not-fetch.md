# The system does not fetch; the boundary starts at the endpoint, and the endpoint is multimodal

The system does not fetch anything - Billy is the fetcher, and it does not need to know how a source arrived. The boundary starting at the endpoint scopes the trust requirement to **what the system was given** rather than to coverage of the world. That requirement is **faithfulness**'s three axes, of which recall is one (`0081`). Because delivery is a paste, the endpoint is multimodal from the first version, and it records the source's **publication** time and not its arrival time - three notices dumped on a Sunday in the wrong order would otherwise let an older fact silently overwrite a newer one.
