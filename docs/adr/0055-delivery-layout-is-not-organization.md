# Delivery layout is not organization; resolution is semantic

The portal's folder tree shows how files are distributed, not how knowledge is organized, and finding the better organization is why the system exists. A pasted intake screenshot therefore carries **provenance and not position**: a node's parent is resolved semantically and never by a path match. The user's own folders are admissible as evidence of the organization he reaches for under pressure, and never as the course's structure.
