# The store accumulates; it is never synchronised against a source

This is not a system kept aligned with a remote, it is a knowledge base that accumulates: things enter, stale or wrong things leave, and everything is classifiable and queryable. There is no full re-read, no diff against a source and no mirror state, because there is no correspondence to maintain. Accumulation is not permission for two conflicting statements to sit side by side.
