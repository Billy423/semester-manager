# Whatever `origin`'s vocabulary becomes, it may not carry a locator

A page reference inside `origin` re-admits the graveyarded `source_ref` through the annotation, so the field may name **how** a claim came to exist and never **where in the source** it came from. The document-class vocabulary exists to satisfy this constraint.

## Considered Options

Letting `origin` say where in the source a claim came from. This is what two independent extraction passes both reached for and what the field's real use wants, which is exactly why the constraint has to be written down: the live record books the two-vocabulary collision as owed and states it as drift between two passes, so a write-rule author reading that record alone cannot tell that one side of the collision is a ruled constraint rather than an accident.
