# Two writes carry no material, and they belong to the coordinator

A write path modelled as *material → extraction → candidate fact → landing* has no route for a write that begins with no material. Two exist:

- **A `progress` row or update.** No event in the world generates a progress state, so no material carries one. `0035`'s *"only the owner authors it"* is a convention and says so in place - *"enforced nowhere, deliberately"* - so it is not the mechanism here; the absence of material is.
- **A correction stated as a claim about a held row.** It is skeleton-shaped by nature, and `0086` bars an extractor from skeleton knowledge, so no extractor can resolve the reference.

**Both belong to the coordinator**, which may write the skeleton: `0045` governs what enters its context, not what it may do.

**The second is narrower than it first looks.** A correction can also arrive as material - #24's first origin is *"A correction arrives as an announcement. Designed for."* - and that path is an ordinary extraction whose collision `0051` detects at landing. What no extractor can produce is a correction that **references a row**.

**The class was already named and is not a discovery.** `CONTEXT.md`'s `origin` carries *"someone saying so"*; #10 records *"the third class is real"*; #24's second origin is *"The user states one. Designed for."* What was missing was a route, not the observation.

**What this does not decide.** Whether either write is confirmed before it is made is #10's, and whether a `progress` row is written at all is #70's first slot. This record places an owner and no more.
