# `closure` is single-source reachability from one node, not an all-pairs matrix

Closure follows one link kind transitively from a single source. The rejected alternative is an all-pairs matrix, and it loses on cost against generality over a graph bounded by ring 0 at roughly **55 obligations for five courses**. That figure carries a scope clause recorded in `0038`: its evidence is two courses of the same shape, with the obligation-dense course excluded throughout.
