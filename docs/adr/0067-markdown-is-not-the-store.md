# Markdown notes are not the store

Manual markdown maintenance is out as the system of record: the information granularity is too fine and too time-sensitive for a devlog-style discipline, and the failure mode is not that notes are wrong but that they are not updated on the day a deadline moves. **The store is typed and written by the system; markdown remains a fine medium for decisions about the system and a bad one for facts inside it.**
