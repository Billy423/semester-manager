# Renderer-introduced truncation is asymmetry, so a fixed-width table is not the course level's shape

A fixed column width forces per-row truncation, and truncation introduced by the renderer is asymmetry introduced by the renderer, which ADR `0039`'s symmetry rule rules out. The ground is not readability - it is the symmetry rule applied to the **renderer** rather than to the observer, which is a widening `0039` does not itself state. The table was rendered over real data first and rejected on what it showed, and rejecting it removes the default with no replacement designed.
