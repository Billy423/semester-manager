# What is fetched is dropped; depth never comes back into the conversation

Depth is added only inside ephemeral contexts and does not come back: what is fetched is rendered, used and dropped, never accumulated. Holding expansions saves refetches and loses anyway, because without discarding, a long-running conversation converges on held-everything **plus** path-dependent bias - both costs, no benefit. The store boundary is the chokepoint for **content**; discard discipline is the chokepoint for **structure**.

The view does not deepen precisely because what is fetched is dropped. In a long-running agent conversation the discard is **not** automatic - compaction is lossy and unpredictable, not a discipline - so the rule is a statement about what the conversation must not be asked to keep, enforced by the tool's return shape.
