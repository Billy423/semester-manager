# The modelling layer is stateless: system-inferred mastery is forbidden

The modelling layer records no state about the owner: it presents concepts and leaves judgment to him. Surviving set-difference queries are structural ("this concept has no artifact covering it"), never personal ("you never opened X"). An agent may surface a progress claim for confirmation but may never resolve one.

Enforcement point: **nowhere, deliberately** - it is a rule about the caller.
