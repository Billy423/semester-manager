# The system makes no assertions about its own completeness

The system never asserts its own completeness or freshness; integrity work runs silently and is not reported as a status. Trust accrues from being useful, and a self-report that can go stale is worse than none because it lies confidently. This is not a rule against speaking: the agent still reports actions it took and still asks before it resolves anything deep.
