# A course is a node, not a namespace

A `course` is a node, so `get(Ref("course","2c03"))` resolves and an `about` link to a course is an ordinary link with no special case. The forcing case is course-level notes: the late-day budget is not a property of any obligation, and without a course node it has nowhere to land.

Source: fall26:records/spec/design.md §3.2
