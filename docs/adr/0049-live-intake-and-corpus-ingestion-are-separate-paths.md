# Live intake and corpus ingestion are two paths, and routing either through the other is a category error

Live intake is a pasted screenshot **read by the session itself** - the harness reads the image, so there is no API call and no token cost. The corpus is page-images that cannot enter a session context at any price, and it goes through an offline pass that is in no tier. Routing either one through the other is a category error, not an optimisation.
