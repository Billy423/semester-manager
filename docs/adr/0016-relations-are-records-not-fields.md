# Relations are records, not fields on the related thing

A relation between two things is its own record, never a field on either end. A note's target is an `about` link, not a `target_id`. The genuine alternative was live and written down - infer relations at read time, "affordable because the layer fits" - and it was overturned by the project's own rigidity rule once `obligation → concept` acquired a mechanism that reads it.
