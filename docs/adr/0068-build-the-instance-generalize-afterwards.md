# Build the instance; the general contract is whatever survives generalization

The instance comes first and forces the template: this design **is** the general work, and the contract is whatever survives generalization afterwards, not something derived up front. Do not clone outward from existing instances. The same posture applies inside the system, wherever a second case is tempting before the first one renders.
