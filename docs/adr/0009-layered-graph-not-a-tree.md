# The skeleton is a layered graph; the model may not cut edges to force a tree

A concept appearing in two places is the truth of the data, not a rendering bug, so the model may not cut edges to force a tree. A file is not the object being modelled: a lecture PDF and a tutorial PDF exist and are used independently, yet both describe one concept. Which spine a view renders is the surface's decision.
