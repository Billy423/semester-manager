### 1. The test's formalisation - deliverable 1

`0101`'s test in its informal wording: *a form belongs in routing's domain if and only if some judgment the coordinator must make ranges over a set that cannot be produced in one return without it.* The first application (#85's resolution, its §7) exposed three questions that change verdicts. Each is answered here, and a fourth the reviews exposed is answered with them.

**(iii) A form is counted at the grain where removing it changes what a chain can produce.** This is the test's own criterion applied to its own unit: `0101` says the test *"admits by what a form lets a chain produce"*. Under it, `FILTER(P and Q)` is a spelling of `FILTER(P) · FILTER(Q)`, so `and` is not a form; `START(ref)` is a spelling of `START(K) · FILTER(id = X)`, as #85 §7 already noted, so the chains below that start from *this obligation* need no form of their own. `or` is a form: without it, `FILTER(P or Q)` is `START · FILTER(P) ∪ START · FILTER(Q)`, a union, which the vocabulary does not contain and which is two returns. `not` and `exists` are each a form: `exists` is what carries a join, and under (i) below `not exists` is what tests absence on one member, which `0003`'s set-difference query is the ruled instance of. #85 §7's *connectives as one form* is replaced. (iii) counts forms; whether each is admitted is §8's, and `or` is not.

**(ii) Two chains produce the same set relative to a judgment.** Two chains produce the same set for a judgment if and only if they differ only at positions the judgment does not range over. Read absolutely over the path set, every distinct chain trivially produces a distinct set and question (i) loses its discriminating power; read absolutely over endpoints, `0101`'s ground for paths - *"a judgment across obligations is a judgment about their relations"* - is discarded. The relative reading keeps `0101`'s output type unchanged and makes each must-judgment declare what it ranges over, which is a column of §3's table.

**(i) *Without it* is read over the candidate forms minus the one under test, including inside `exists`.** #85 §7's provisional reading is confirmed. The fixed point the body feared - that the set of forms is what the test generates - dissolves under (iii): two spellings of one production are one form, so a candidate can never be excluded by a spelling of itself. The concrete case #85 §7 named, #88's *covered* disposition admitting `nodes_without` as a form and thereby removing the ground under `exists`, does not arise: `nodes_without(K, L, D)` is `START(K) · FILTER(not exists(MOVE(L, D)))`, a spelling, and whether it is separately named at the surface is #88's and says nothing to the test.

**(iv) A superset that carries the discriminator does not produce the set.** A judgment's set is the set as the judgment defines it. If a chain that returns a wider set with the deciding field visible on every member counted as producing the judgment's set, then no `FILTER` would ever be necessary at a width the coordinator can hold, and #85's first application admitted `FILTER` on exactly the ground that *no crossing reaches a date*. So the test counts the set, not the affordability of a superset; affordability is `0101`'s separate width question. Re-run over #85 §7's table, (iv) changes no verdict there. **Its discipline on this record:** wherever the standing intent returns a member the coordinator then judges out, this record either shows no must-judgment ranges over the narrower set (§4, *the active ones*) or states the reading under which the member is in and wakes it (§4, `optional` and `done`).

**The test can now be run.** Its instrument standing is unchanged: a finding at #87 or #88 that it admits or excludes wrongly revises it.

### 2. The two type questions - ruled here

**A crossing may be optional.** A member whose crossing finds no relation is kept with an empty position, and the empty position names the relation it ranged over. Ground: *what each obligation requires you to know* is in `CONTEXT.md`'s opening sentence, so it is a must-judgment; a mandatory crossing returns only the obligations that require something, and the reader cannot tell *requires nothing recorded* from *out of range*, which is the silence `0081` forbids and the omission axis of **faithfulness** names; the complement fetched separately is two returns, which `0101`'s premise forbids. **Two consequences the must-list forces, ruled with it:** optionality scopes over the crossing together with any selection on its target or on the link - `MOVE(about, pointed-by)` reaches both annotation kinds by `0012`'s signature, and a kind predicate applied after an optional crossing would keep an obligation with a `sticky_note` and no `progress` by the crossing and drop it by the predicate, so *an optional step is empty when nothing satisfies the step's whole selection*, written below as `MOVE(L, D)[selection]?`; and a step from an empty position yields an empty position with the member kept, since J3 composes a second optional crossing onto J2's and an obligation with no `requires` link would otherwise be dropped at the second step by the silence the first was made optional to prevent. A path may therefore end at an empty position; every non-empty node position is addressable, and which one the coordinator spends its next call on is its judgment. The spelling of all of this is the grammar's.

**A non-endpoint node position carries one field set per kind, of line depth, derived by the criterion for the judgment; and the criterion runs over every position.** `0101` states its criterion on *"a routing result's endpoint"* and leaves what a non-endpoint position carries to the grammar; #85's §8 and #86's unblocking comment assign that question here. `0039` scopes symmetry to the set the judgment ranges over; that a judgment over paths may range over any of their positions is this record's step, as §1 (ii) already makes it; so the criterion applies at every node position and not only the last: a position carrying only an id would make *which concept* in job 2 cost one `look_at` per intermediate, which `0101`'s premise forbids; a position carrying a block would carry depth the discard (`0043`) and `0095` bar. One kind at two positions of one result carries one set, derived for that judgment, at both. A position's field set is not the kind's line: §5 derives the obligation position's and finds it differs from obligation's line in both directions. `0101`'s wording is amended from *endpoint* to *position*, and its grammar clause split (§10). What a **relation** position carries, and when a node's `kind` rides a position, are grammar questions this record used and does not rule (§5b).
